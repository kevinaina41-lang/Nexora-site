Politique de Confidentialité

1. Données collectées

Nexora MDG collecte les données suivantes via son formulaire :

  • Nom
  • Adresse email
  • Numéro de téléphone
  • Type de projet et de paiement
  • Budget estimé
  • Message

2. Utilisation

Vos données sont utilisées uniquement pour :

  • Répondre à vos demandes
  • Établir un devis
  • Communiquer sur votre projet
  • Améliorer nos services

3. Protection

Nexora MDG s'engage à :

  • Ne jamais vendre vos données
  • Ne jamais les partager sans consentement
  • Les sécuriser techniquement
  • Les conserver uniquement le temps nécessaire

4. Vos droits

Vous disposez des droits suivants :

  • Accès : consulter vos données

Pour exercer ces droits : nexora.contact@gmail.com

5. Cookies

Notre site n'utilise pas de cookies de tracking. Seuls des cookies techniques essentiels peuvent être utilisés.
